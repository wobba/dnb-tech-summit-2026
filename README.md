# Open source after the agent acceleration

Mikael Svenson, DNB Tech Summit, Oslo, 12 November 2026.

[Play the presentation](https://wobba.github.io/dnb-tech-summit-2026/) ·
[Download the PDF](https://wobba.github.io/dnb-tech-summit-2026/dnb-tech-summit-2026.pdf)

This folder contains the 35-slide presentation without speaker notes.

- `dnb-tech-summit-2026.pdf`: static slides, with no notes.
- `index.html`: playable slides, including animations and the intro video.

Open `index.html` in a browser. Use arrow keys to navigate, `Esc` for the
overview and `F` for fullscreen. On the first slide, click "Pull out a memory"
to play the muted intro clip.

For web sharing, this folder is published as the root of a GitHub Pages site.
All presentation assets are local; no build step or CDN is required.
The PDF and HTML do not include the live demo itself or its build prompt.
